# workspace-status

Static status pages for data pipelines in the private `below-1/workspace` repo.

Deploy by pushing `main`/`master`; GitHub Actions publishes `dist/` to Pages.

## Local

```sh
npm install
npm run dev
npm run check
npm run build
```

JSON in `src/data/` is generated by the private repo pipeline
`publish-web` and committed here manually after review.
