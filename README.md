# workspace-status

Static status pages for data pipelines in the private `below-1/workspace` repo.

Deploy by pushing `main`/`master`; GitHub Actions publishes `dist/` to Pages.

## Local

```sh
npm install
npm run dev
npm run check
npm run build
```

JSON in `src/data/` is generated by the private repo pipeline
`publish-web` and committed here manually after review.

`public/data/paruh-nip-lookup.json` is the approved NIP-level lookup dataset for
the PPPK Paruh Waktu status page. It contains NIP, name ASN, and safe defect
detail (`code`, raw NIP cell, human-readable validation message), but no email
address, sender name, subject, filename, or `fixed_by`.

`public/data/paruh-email-log.json` is the approved email-validation dataset. It
contains the institutional sender address and invalid NIP numbers, but no
sender name, subject, source filename, person name, or raw defect detail.
Aggregate JSON in `src/data/` remains free of NIP, names, and email addresses.

https://commons.wikimedia.org/wiki/File:Coat_of_Arms_of_East_Nusa_Tenggara_NEW.png
